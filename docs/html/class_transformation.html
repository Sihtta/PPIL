Detailed Description

Classe de base des transformations géométriques.

Cette classe hérite de VisiteurForme afin d'appliquer le pattern Visitor aux différentes formes géométriques. Les classes concrètes comme Translation, Rotation et Homothetie redéfinissent les méthodes visit.
